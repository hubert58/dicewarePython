# diceware

Petit utilitaire Python pour générer des mots aléatoires pour créer des mots de passe.

## Prérequis
- Python 3.8+

## Usage
- Placez votre fichier de mots à la racine du projet (ex. `liste.de.mots.francais.frgut.txt`).
- Exécutez :

```
python search.py liste.de.mots.francais.frgut.txt
```

## Description
- `search.py` est un script simple pour générer des séquences de mots aléatoires à partir d'une liste de mots français.
